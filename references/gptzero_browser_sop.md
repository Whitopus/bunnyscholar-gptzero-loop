# GPTZero 浏览器操作参考

已有报告、截图或分享链接时，从那份结果开始。新测试用当前宿主可用的浏览器；如果浏览器无法上传或读取文件，用户可以在同一账户自行测试并提供结果。 [GPTZero](https://app.gptzero.me)

## 文本或整篇 PDF

| 目的 | 做法 |
| --- | --- |
| 比较几段文字 | 把需要比较的段落粘贴到 GPTZero 文本框，尽量用相同的输入范围与跟踪到的扫描模式。局部结果只代表该次输入。 |
| 需要分页结果 | 上传匹配当前稿件的 PDF；如果界面提供分页视图，记录页码、分数或标记，并对照 PDF 文本定位 Word 段落。 |
| 卡在段落标黄或付费提示 | 结果视图、可用功能与额度可能因账户而不同。先查看当前的普通扫描或已有结果，可关闭的推广弹窗可直接关闭。 |

某些浏览器中，富文本框经自动填充后字数仍显示零。先聚焦输入框，再用宿主支持的粘贴或文本输入动作。上传路径以宿主浏览器的提示为准，只有上传工具需要文件暂存时才用 `export-pdf --stage-to`。

如果文件选择器没有打开，检查是否有试用推广盖在上传按钮上。关闭当前推广后再触发选择器。上传后先观察 `Processing document` 和结果区，有些 PDF 会自动开始扫描；看到结果后可切到 `Basic Scan`，避免又点击一次扫描。

Codex 内置浏览器实测中，游客页提示文本至少 250 个字符，276 字符样例通过粘贴完成了 `Basic Scan`。实际门槛以页面提示为准。若片段过短，可带上连贯的上下文，并说明分数覆盖的文本范围，或者依照已有报告分析。

## 登录、限制与结果核对

- **用户要登录，或当前任务确实需要登录。** 先检查当前会话。页面还没登录时，由 Agent 打开 `Log in`，等登录选项出现后把浏览器交给用户。根据实际界面提示可以选原来用过的登录方式。Codex 实测页提供了 `Continue with Google` 和 `Continue With Email` 等入口。可直接完成的游客扫描仍可按用户需求使用。
- **交接时把话说到当前按钮。** 例如「GPTZero 登录选项已打开。选你之前用过的登录方式。回到 GPTZero 扫描页后把控制权交给我，我接着上传这份 PDF。」验证码或二次验证出现时也只说明当前这一步。用户说「好了」以后，Agent 检查原会话或登录流程打开的新标签页，确认账户状态，继续原定操作。仅要求登录时，核对会话后即可结束。
- **用户想换号。** 打开当前账户菜单，优先使用可见的切换账户选项。Codex 的实测会话中，头像菜单显示的是 `Log out`。若只有退出登录，检查退出是否会影响手上的工作，需要时先留好待扫描文件或本轮已取得的结果，再从登录页切到目标账户。第三方登录又选回旧账户时，引导用户在账户选择器里选另一个账户，或使用宿主已提供的其他浏览器资料。回到 GPTZero 后，核对界面可见的账户标识。界面只显示头像等无法可靠区分的标识时，由用户在页面上确认账户后再提交扫描。
- 遇到实际额度或频率限制，保留已看到的结果。说明界面显示的限制和当前还能完成的部分。按用户意图继续，例如稍后再试、使用已有报告，或按其明确要求切换到指定账户。
- 记录界面实际显示的分类、分数和扫描范围。没有分页视图时，只提供这次能核实的结果。整篇的 `Human`、`Mixed`、`AI` 跟逐页评分、句子高亮分别按报告自身含义解释。

<a id="export-report"></a>

## 导出 GPTZero 原生 PDF 报告

用户需要检测报告文件时，在结果页找 `Export` 和 `Download PDF Report`。批次结果页的 `Export` 无响应时，从左侧 `Scans` 进入历史记录，按文件名找对应版本。点击记录可能打开新标签页，应接回单文档结果页，再点 `Export`，等弹窗里的 `Download PDF` 可以点击后下载。按宿主返回的路径找成品，核对报告中的文件名和可见分数，再归档到交付目录。

原生报告可能重新排版正文，只列整篇概率和高亮。需要逐页评分时，另外记录扫描页的 `Page by page scan`，或按交付需求截取该区域。当前会话无法下载时，可以保留已核实的检测结果。只有用户要求发布分享链接时，才开启报告的链接共享。
